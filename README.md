# WeighingDesk

برنامج سطح مكتب لإدارة أوزان المركبات، مبني باستخدام Windows Forms و.NET 8. يحفظ سجلات الوزن محلياً على الكمبيوتر، ويدعم الاتصال بمؤشر وزن عبر RS-232.

## المتطلبات

- Windows 10 أو أحدث.
- Visual Studio 2022 مع مكونات تطوير .NET لسطح المكتب، أو .NET 8 SDK.
- الميزان وكابل الاتصال المناسب عند تجربة الاتصال الفعلي.

## فتح المشروع وتشغيله

افتح `WeighingDesk.slnx` في Visual Studio، وانتظر استعادة حزم NuGet، ثم شغّل المشروع. يمكن استخدام **الوضع التجريبي** لتجربة الشاشات وحساب الوزن دون ميزان.

## الوظائف

- تذاكر مركبات بتسجيل الوزنة الأولى والثانية وحساب الوزن الصافي.
- قاعدة بيانات SQLite محلية، وإعدادات محفوظة محلياً للمستخدم.
- إعدادات اتصال تسلسلي RS-232، ودعم قراءة بيانات مؤشر Tunaylar Load Line 2.
- بحث وتقارير وطباعة وتصدير إلى Excel.
- واجهة عربية وإنجليزية وكردية، وإعدادات لقالب التذكرة والطباعة.

## تخزين البيانات

تُحفظ قاعدة البيانات وإعدادات الاتصال في مجلد بيانات المستخدم المحلي تحت `%LOCALAPPDATA%\WeighingDesk`.

## تنبيه للاتصال بالميزان

بروتوكول المنفذ وإعداداته تعتمد على طراز المؤشر وطريقة ضبط منفذ الإرسال فيه. اختبر إعدادات COM والسرعة والبارتي وعدد البتات ونمط الاتصال على جهازك قبل استخدام البرنامج في عمليات فعلية. وضع المحاكاة لا يتصل بالميزان ولا ينتج قراءات حقيقية.
